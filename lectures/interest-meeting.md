# **BUILD** together at Dev Club!

Dev Club is where people learn web dev, build projects, and ship them.

- **Learn**: pick up a new skill at your own pace or teach others what you know.
- **Build**: turn new knowledge into a working project together collaboratively.
- **Ship**: release a finished project into the world for everyone to see/use.
- We are part of **Hack Club**!

---

# What is Hack Club?

Hack Club is a global community of high school coding clubs.

- "Hackers" are teens like you who learn, build, and ship projects!
- Get to know and learn with builders from all over the world.
- Collaborate on projects together with friends.
- We host workshops, YSWS, competitions, and hackathons for free prizes.
- Prizes include laptops, iPads, 3D printers, and electronics!

- Experienced developers, curious beginners -- anyone!
- Start from anywhere and learn at your own pace.
- Want to contribute? You can host guest lectures and mentor others!

# What will I learn?

- **Web dev languages**: HTML, CSS, JavaScript, TypeScript, Markdown
- **Frontend technologies**: React, Astro, Svelte
- **Backend frameworks**: Node.js, Next.js, Express.js, Bun, Django
- **Database concepts**: SQL, Postgres, Redis
- **Development tools**: Git, GitHub, Linux, Docker
- **Internet deployment**: HTTP/HTTPS, NGINX, DNS, Vercel

# How do I learn?

- No experience required. (seriously!)
- Topics progress throughout the year, skills are built on top of each other.
- Work on projects together, ask an officer or mentor if you need help.
- Occassional (guest) lectures for any technical topics.
- Meeting slides are always posted on our website. (tjdev.club)
- Self-paced options: Odin Project, W3Schools, MDN Web Docs, etc.
- **MOST IMPORTANTLY**: learn by **BUILDING REAL PROJECTS**!
